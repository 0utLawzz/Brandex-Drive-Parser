# Security Policy

## Reporting a Vulnerability

Please report security issues privately to **net2outlawzz@gmail.com** with the subject `[SECURITY] Drive-Data`.

## Scope notes

- Never commit `credentials.json` or other Google Service Account keys.
- Keep Google Sheet IDs and shared folder paths out of public commits when they contain client data.
- Prefer environment variables or a local untracked config for production paths.
