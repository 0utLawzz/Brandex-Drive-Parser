🚀 Features

Dynamic Rules

Edit case triggers and column outputs without touching Python code. Add custom regex patterns on the fly.

🛠️ Architecture

Drive-Data is structured around three logical layers:

1. CLI Interface Layer

Interactive numbered text menu. Handles directory scope (All Clients / Consultants / Both / Custom Path) and output destination (Local / Google Sheets / Both).

2. Directory Scanning & Pattern Matching

Recursively traverses paths with os.walk. Applies predefined regex patterns to classify each file into trademark categories and builds structured records.

3. Export Layer

  • Local: pandas DataFrame → openpyxl → .xlsx + .csv
  • Google Sheets: gspread + Service Account → append records with formatting

💻 Setup & Installation

Requirements

  • Python 3.7+
  • Google Cloud Service Account with Google Sheets API and Google Drive API enabled

Step-by-Step

1. Clone the repository

git clone https://github.com/0utLawzz/Brandex-Drive-Parser.git
cd Brandex-Drive-Parser

2. Install dependencies

pip install -r requirements.txt

3. Configure Google credentials

Create a service account → enable Sheets + Drive APIs → download key as credentials.json → place in project root → share target Google Sheet with the service account email (Editor).

4. Configure main.py (if needed)

SHEET_ID = "your_google_sheet_id"
SHEET_NAME = "List"

5. Run

# Windows
run.bat

# Python
python main.py

🔧 Troubleshooting

  • gspread.exceptions.SpreadsheetNotFound — Check Sheet ID and that the sheet is shared with the service account email.
  • FileNotFoundError: credentials.json — Ensure the JSON key file is in the project root.
  • Permission errors on export — Make sure the local export directory is writable.
